# Reference material

This directory contains source material used to understand and implement ASTERIX
message formats. Keep each publisher in its own subdirectory and record the
source URL, publication metadata, retrieval date, and checksum wherever
possible.

The source documents remain the property of their publishers. Do not treat this
mirror as a replacement for the current, authoritative publication.
